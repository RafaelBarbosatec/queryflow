# Queryflow

**Write SQL in Dart, not strings.** Queryflow is a fluent query builder and schema manager for MySQL and PostgreSQL. It generates parameterized SQL, maps rows to typed models, and keeps table definitions next to your code.

```dart
final users = await db
    .select('users', ['id', 'name', 'email'])
    .where('active', Equals(true))
    .orderBy(['name'], OrderByType.asc)
    .limit(20)
    .fetch();
```

## Install

```bash
dart pub add queryflow
```

Requires Dart `>= 3.0.0 < 4.0.0`. Queryflow uses `dart:io` and TCP sockets, so it runs on the Dart VM and on Flutter mobile/desktop — not on Flutter web.

    ```dart
    final db = Queryflow.postgresql(
      host: '127.0.0.1',
      port: 5432,
      userName: 'postgres',
      password: 'secret',
      databaseName: 'app',
    );
    ```
  </TabItem>

Do not forget to close the connection when your application shuts down:

```dart
await db.close();
```

## What makes it different

- **Parameterized by default.** Values become `?` placeholders on MySQL and `$1, $2, ...` on PostgreSQL. Raw queries can use either style on PostgreSQL.
- **Dialect-aware.** Identifier quoting, auto increment, `RETURNING`, enum handling, and type mapping are generated per database.
- **No code generation.** Define adapters by hand and keep full control over how your models map to columns.
- **Explicit schema management.** `synchronize()` creates tables and adds missing columns; destructive changes are opt-in.
